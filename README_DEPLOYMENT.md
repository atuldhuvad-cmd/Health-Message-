# Health Infographic Studio 2.2

Static mobile deployment candidate for GitHub Pages and Android Chrome.

## Deploy with GitHub Pages

1. Upload this directory’s contents to a dedicated repository root.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select the deployment branch and `/ (root)`.
4. Open the published repository URL once while online and allow the artwork cache to complete.

All paths are relative and work below `https://USERNAME.github.io/REPOSITORY/`. The app contains no credentials and does not require Make, a laptop, or external artwork hosting. Make handoff is optional, manual, and metadata-only.

## Daily mobile workflow

Open the app, tap **Generate Today’s Poster**, confirm READY/QA PASS, then tap **Share Poster**. Browsers without PNG file sharing download the current PNG and explicitly report that fallback.
